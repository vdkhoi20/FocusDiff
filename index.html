Abstract

Editing the intended object, not the whole scene.

FocusDiff is a tuning-free framework for localized text-guided image editing. Given a user mask and a target prompt, it refocuses diffusion attention on the selected region by selectively blurring non-editing areas, then transfers the target object identity, structure, and appearance back into the edited image.

The method integrates CPAM-style context preservation to keep background regions stable, reducing spillover edits while remaining practical for small objects and cluttered scenes. Beyond 2D editing, FocusDiff supports 360-degree indoor panorama editing with a VR mask-generation interface.

Method

Refocusing cross-attention with context-preserving denoising.

01

Refocus

Blur non-target regions so attention concentrates on the region the user actually wants to edit.

02

Transfer

Use masked attention to transfer identity and structure from the edited object flow to the target flow.

03

Preserve

Reuse context features to protect unmasked regions and maintain global coherence.

Benchmark

LIMB: Localized Image Manipulation Benchmark.

LIMB is curated from PIE-Bench for fine-grained localized image manipulation. It contains multi-object scenes, annotated masks, and prompts designed to evaluate whether a method edits the requested target while preserving the unmasked scene.

  • 30 multi-object images
  • 100 localized editing annotations
  • Small-object cases for realistic failure modes
  • Shared masks for fair comparisons with CPAM and other zero-shot editors
